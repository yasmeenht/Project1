# Personal Portfolio

A responsive personal portfolio website created to showcase my background, experience, skills, projects, and journey as a Computer Science graduate and aspiring Full-Stack Developer.

## About the Project

This portfolio was developed as part of my training at Orange Coding Academy. The goal was to create a responsive and visually engaging website that represents both my technical background and personal style.

The website includes information about my education and experience, an overview of my technical and soft skills, and a showcase of my projects.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Desktop and mobile navigation
- Interactive About Me section
- Experience and qualifications sections
- Technical and soft skills showcase
- Interactive project showcase
- References section
- Social media and contact links
- Hover effects and CSS animations

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

portfolio/

## Responsive Design

The website uses CSS media queries along with Flexbox, Grid, and Bootstrap components to adapt the layout for different screen sizes.

Some interactions are also adjusted depending on the device. For example, the project showcase uses hover interactions on desktop and selectable controls on smaller screens.
